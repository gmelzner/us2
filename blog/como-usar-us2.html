Guía Completa: Cómo Usar US2 para Mejorar tu Relación

US2 no es solo un test. Es una herramienta para abrir conversaciones, trackear progreso y celebrar logros juntos. Así es como sacarle el máximo provecho.

3 minutos de test pueden cambiar meses de dinámicas.

Paso 1: El Test Inicial

Cada uno completa el test por separado. Es importante ser honesto, no responder lo que 'debería' ser sino lo que realmente pasa.

El test evalúa 9 categorías de gestión del hogar y genera un perfil único para cada uno.

💡 Tip: No miren las respuestas del otro hasta que ambos terminen.

Paso 2: El Dashboard Comparativo

Una vez que ambos completaron el test, ven el radar chart con las diferencias. Las áreas con mayor brecha son los 'puntos ciegos' donde hay que trabajar.

El análisis de gap muestra específicamente dónde hay más diferencia de percepción.

💡 Tip: Usen los insights como punto de partida para conversar, no como arma para atacar.

Paso 3: Los Logros Invisibles

Cada día, registren las pequeñas tareas que normalmente pasan desapercibidas. El otro las aprueba y suman puntos.

Esto hace visible el trabajo invisible y genera un hábito de reconocimiento mutuo.

💡 Tip: Sean específicos. 'Recordé comprar leche' es mejor que 'fui al super'.

Paso 4: Objetivos y Recompensas

Definan objetivos juntos y elijan una recompensa para cuando los alcancen. Puede ser una cena especial, un día de spa, o lo que quieran.

Celebrar los logros juntos refuerza el trabajo en equipo.

Paso 5: Repetir y Comparar

Hagan el test de nuevo cada mes o dos. El gráfico de evolución mostrará si la brecha se está cerrando.

Cada badge y desafío completado es un recordatorio de que están progresando juntos.

Resumen de los 5 Pasos:

  1. Hacer el test por separado (3 min c/u)
  2. Revisar el dashboard comparativo juntos
  3. Registrar logros invisibles cada día
  4. Definir objetivos y recompensas en pareja
  5. Repetir el test mensualmente para ver progreso
